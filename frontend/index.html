🚀 快速开始

从编译 C++ 核心到打开网页版，共 6 步（点击步骤可展开 / 收起）

1

Windows 已用 g++ 14 验证，产物 libfastroute.dll。

bash
# Windows（已用 g++ 14 验证，产物 libfastroute.dll）
cd native
g++ -std=c++17 -O2 -shared -I include -I src \
    src/route.cpp src/route_c_api.cpp src/jsonlite.cpp -o libfastroute.dll

# 运行单元测试
g++ -std=c++17 -O2 -I include -I src \
    src/route.cpp src/route_c_api.cpp src/jsonlite.cpp tests/test_route.cpp -o test_route && ./test_route

macOS/Linux 相应产出 libfastroute.dylib / libfastroute.so；也可用 CMake 构建。

2
bash
cd backend
pip install -r requirements.txt
uvicorn app:app --host 0.0.0.0 --port 8000
3
bash
cd backend
python scraper.py --lat 31.2304 --lng 121.4737 --radius 2000 --out stations.json

# 接入真实地图平台：
#   高德  MAP_PROVIDER=amap  AMAP_KEY=xxx python scraper.py ...
#   百度  MAP_PROVIDER=baidu BAIDU_AK=xxx  python scraper.py ...
4
  • 用 Android Studio 打开 android/ 目录（AGP 8.5.2 / Kotlin 1.9.24）。
  • 构建时通过 app/src/main/cpp/CMakeLists.txt 自动把 native/ 的 C++ 源码编入 libfastroute.so，供 JNI 调用。
  • 模拟器运行（BASE_URL 已指向 http://10.0.2.2:8000，即宿主机后端）；真机请把 api/ApiClient.kt 的 BASE_URL 改为宿主机局域网 IP。
5
  • 新建 iOS App 工程（SwiftUI，iOS 17+），把 ios/PowerBankFinder/ 下源码加入。
  • Build Settings 配置：Objective-C Bridging Header → PowerBankFinder-Bridging-Header.h；Header Search Paths → 添加仓库根 native/include；将 native/src/{route,route_c_api,jsonlite}.cpp 加入 target 的 Compile Sources。
  • 模拟器运行（ApiClient.baseURL 指向 http://127.0.0.1:8000）；真机请改为宿主机局域网 IP。

frontend/ 是纯 HTML+CSS+JS 的 Vue3 单页应用（Vue 已本地 vendored，离线可用），由后端直接托管，不需要任何构建/安装——本页正是它。

方法路径说明

🧠 核心实现说明

三大核心模块的实现原理

⚙️ 最快路线算法（C++）

native/src/route.cpp 实现：dijkstra() 优先队列优化的单源最短路径；a_star() 以球面直线距离（时间模式按 1.4 m/s 换算为时间下界）为启发式加速；无向图、支持 Distance / Time 两种边权，route_c_api.cpp 导出 C 接口。

🪫 低电量自动定位（1%）

Android：ACTION_BATTERY_CHANGED + BatteryManager.EXTRA_LEVEL，≤1% → 定位 → /api/emergency。iOS：UIDevice.batteryLevel 通知，≤1% → CLLocationManager → /api/emergency。

🕷️ 地图抓包（Python）

scraper.py 抽象 MapProvider（Mock / 高德 / 百度），按环境变量切换，抓取结果统一输出为 stations.json，供后端站点接口消费。

⚠️ 免责声明：本项目为教学/演示用途，站点坐标与库存为模拟数据；真实接入地图数据需自行申请 高德/百度开放平台 API Key，并对接真实柜机厂商库存接口。

  1. 启动后端（CD 到 backend/ 目录）： uvicorn app:app --host 0.0.0.0 --port 8000 · 后端未连接，请先启动 · 后端已连接 ✓
